# Using OpenShot

Drop an image or video onto the canvas, click the empty area to choose a file, or paste an image from the clipboard. The editor fits the media without stretching it. There is no sample screenshot to remove first.

## Mockup

Open the model picker at the top of the Mockup panel. Screenshot keeps your media as a plain image. Browser and application frames add window chrome. Device entries use licensed 3D models; Display shows the screen without hardware. The compatibility mode uses front-view model renders when WebGL is unavailable.

Replace media in the left panel, or open the media picker below the canvas to reuse an image already loaded in the session. Multiple screens can contain different images. Device model credits are available from the model details and the information button.

Choose a frame style, corner treatment and shadow. More frame styles reveals Retro, Card, Stack and Stack 2. Adjust light opens a pad that controls the shadow direction and distance. Adaptive shadows use the media's colors.

Video media adds audio, trim and playback speed controls. Audio is muted by default. Turning it on enables preview audio and audio in MP4/WebM exports.

## Frame and layout

The Frame panel controls canvas size, background, effects and watermark. Choose a preset size from its top button or use Custom size. Pick a gradient, color or uploaded image. Magic colors are sampled locally from your media. Additional backgrounds and photo search are in Background settings.

The right panel controls position, zoom, tilt and rotation. The one/two/three controls create a screen arrangement. Choose a layout preview to apply it, or drag the pad for a custom position or tilt. Drag a screen on the canvas to move it. More adjustments contains crop, flip, brightness, contrast and other media controls.

The buttons below the canvas open media, text/shapes and layer settings. Templates sit beside the project menu at the top. Narrow screens put the main panel behind the settings button.

## Animate

Click Animate, then Add animation. Select the new clip to edit its target layout and transition duration. Drag it along the animation row to change its time; drag an edge to change its duration. The base layout appears outside the clip's interval. Scrub the playhead to inspect intermediate frames, or press Play.

Animation settings contains easing, frame rate, motion presets and explicit keyframes. Choosing a preset clears timed layout clips and keyframes. Adding an explicit keyframe clears timed layout clips. This keeps one animation method in charge of each layer.

## Export and save

Export opens image and animation settings. Choose the format, scale and frame rate, then save. MP4 and WebM include audio from unmuted video screens. PNG/WebP/WebM keep a transparent background; MP4 uses black. GIF is silent and uses binary transparency.

Device models under CC BY include artist credits with the export, and credits are also available through the information panel. PNG/JPG/GIF metadata and MP4/WebM metadata carry a copy. Keep readable attribution with published renders; services can strip metadata.

The project menu contains Save project, Open project and Share project. Autosave stores the active project on the current device. Project files embed the media and work without the original source files. Share links embed a compressed project in the URL fragment. Anyone who receives the complete link can open its contents, and large media is better shared in a project file.

The desktop download button opens packages for Windows, Linux and both Mac architectures. The desktop editor also supports native screen/window capture from the project menu.
