# Reference review

The reference was Shots 1.5.93 beta, inspected in its live editor using an actual desktop screenshot and phone screenshot supplied for testing. Those files are private fixtures and are not included in this repository.

The first release was built before enough of these interactions had been tested. This revision replaces the initial illustrated device frames, reorganizes the editor around the observed controls, and records where comparison remains incomplete.

## Verification limits

The browser used for this review disables WebGL. All seven compatibility frame openings were checked with uploaded media. GPU rendering code compiles and uses the same model orientations and display names validated during asset preparation, but live GPU appearance was not verified in that browser. Compatibility frames preserve photographic model detail but do not reveal new side/back geometry when tilted. The generic monitor's compatibility frame has a plain metal finish because its KTX2 texture could not be decoded by the offline renderer.

The timed layout interpolation is an independent implementation of the observed workflow. It is not a measurement of the reference's private easing algorithm. Reduced-motion settings suppress editor transitions.
